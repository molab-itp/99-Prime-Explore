# [99-Prime-Explore](https://github.com/molab-itp/99-Prime-Explore)

- explore the density of prime numbers

## Web version (p5.js)

- [v1-p5js](v1-p5js/) — p5.js port of the SwiftUI PrimeExplore app
- Live: https://molab-itp.github.io/99-Prime-Explore/

Deploy: pushing to `main` runs [.github/workflows/pages.yml](.github/workflows/pages.yml),
which publishes every top-level folder containing an `index.html` (v1-p5js, future v2-…)
plus a generated index page. Preview locally with `scripts/build-site.sh` and any static server.

One-time setup: repo Settings → Pages → Source: **GitHub Actions**.
